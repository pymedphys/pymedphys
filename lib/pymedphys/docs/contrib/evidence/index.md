# Scientific evidence

These records explain how particular scientific and performance claims were
checked. Each applies to its named revisions, inputs, environment, and
achieved coverage. Use the record's reproduction procedure when checking the
same claim, and retain a new experiment separately when those conditions change.

The DICOM coordinate validation record separates independent geometry checks,
fixture provenance, historical replay, and ongoing regression coverage. The
gamma catalogue distinguishes three recorded performance experiments from
the tools for collecting a new comparison.
