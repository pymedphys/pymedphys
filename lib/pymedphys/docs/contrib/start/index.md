# Start contributing

These pages take a new contributor from a computer with Git and uv to a small
pull request that a maintainer can review. They describe the current source
checkout. You need a GitHub account to submit a pull request; reading the source
and checking changes locally does not require push access.

1. [Set up a development environment](setup.md). You will have an editable
   installation tied to your checkout, with the project's locked tools.
2. [Make your first contribution](first-contribution.md). You will have a focused
   branch, a checked documentation change, and a pull request with useful evidence.
3. Continue with [development how-tos](../guides/index.md) for code changes and
   [testing and scientific validation](../validation/index.md) for their evidence.

Questions about using or developing PyMedPhys belong in
[Discussions](https://github.com/pymedphys/pymedphys/discussions). Use
[Issues](https://github.com/pymedphys/pymedphys/issues) for reproducible bugs.
Describe the expected behaviour and give a small synthetic example where possible.
Read the [contribution policy](https://github.com/pymedphys/pymedphys/blob/main/CONTRIBUTING.md)
before sharing data or submitting work.
