.. warning::

   **Research use only.** The Pinnacle Export Tool is intended for research
   purposes only. Do not use it clinically. Inclusion in the public Python
   API does not imply clinical suitability or clinical validation.

   Some conversion values are hard-coded rather than taken from the source
   data. Conversion support and validation vary by DICOM object and Pinnacle
   version, and some objects may not be converted correctly. Before using the
   output in research, compare it with the corresponding DICOM objects
   exported directly by the same Pinnacle version.
