# Repository guidance

## Language

Use Australian/British English for prose, documentation, comments, user-facing
text, reviews, commit messages, and PR descriptions. Prefer spellings such as
behaviour, colour, analyse, organise, optimise, and anonymisation.

Preserve existing code identifiers, command/API names, official product names,
and exact quotations where their spelling must remain unchanged.

## Pull request scope

Keep each PR focused on one coherent topic. Split independent audit corrections
into smaller PRs so maintainers can review and merge them separately.
